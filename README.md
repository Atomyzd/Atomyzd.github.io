# Homepage as CV: 主页即简历

个人主页就是简历。所有信息写在 `data/` 目录下，浏览器打开 `edit.html` 编辑，打开 `index.html` 查看主页。在主页上选好语言和分区后，点 **CV (PDF)** 即可导出对应的 PDF 简历。无需安装 Node、Rust 等环境。

## 为什么做这个项目

投教职或做学术展示时，维护个人材料通常会遇到下面几个问题：

- **多份材料不同步**：个人主页、中文简历、英文简历分开维护，新增一篇论文或一段经历，三处都要改。
- **分区标准因校而异**：不同学校认可的分区不同（中科院、JCR、新锐），对 CCF 的认定也不同。每投一所学校，论文的分组和各档篇数都要重新调整。
- **条目顺序需要手排**：经历和项目要按时间倒序；同一档论文要按作者位置、出版年份、录用状态重排。每次新增条目都要手动调整位置。
- **本地环境依赖重**：常见的主页模板依赖 Node、Jekyll、Hugo 等工具，换电脑或隔段时间再改，往往要先重配环境。

这个仓库把主页和简历合在一起，用浏览器直接编辑和导出：

- 中英文内容存于同一份数据，在 `edit.html` 中集中修改，支持中文自动填充英文。
- 主页可随时切换中/英、中科院/JCR/新锐分区，以及是否计入 CCF；导出 PDF 时所见即所得。
- 经历、项目、论文全部按规则自动排序：
  - **教育与工作、科研项目**：按开始时间从近到远排列，未填开始时间的排在最后。
  - **代表性成果**：在当前分区的每一档内，先按作者位置（第一作者 → 其他位置 → 未出现在作者列表中），再按出版年份从近到远排列；无年份的（如 Just Accepted）排在同类最前，Major Revision 排在该档最后。
- 纯静态文件，本地零依赖，双击即可打开，推送到 GitHub 即可部署。

## 使用方法

1. 用浏览器打开 `edit.html`。
2. 按步骤填写：网站设置、个人信息、研究兴趣、教育与工作、科研项目、代表性成果、学术服务。
3. 点击保存：
  - Chrome / Edge：选择项目目录（或其中的 `data` 目录），文件会直接写回本地。
  - 其他浏览器：自动下载 `data.zip`，解压后覆盖原有的 `data` 目录。
4. 打开或刷新 `index.html`，在右上角和论文栏选好语言与分区，点击左侧 **CV (PDF)**，在打印窗口中选择「另存为 PDF」。导出时文件名会自动设为 `姓名 - CV - 分区`。

## 目录说明


| 文件                     | 说明                                          |
| ---------------------- | ------------------------------------------- |
| `index.html`           | 个人主页与简历打印页（顶栏导航在此文件中修改）                     |
| `edit.html`            | 本地可视化编辑页                                    |
| `data/site.js`         | 页面标题、默认语言、个人简介                              |
| `data/profile.js`      | 姓名、单位、职位、头像路径（示例为 `assets/yg.jpg`）、指标、链接、邮箱 |
| `data/research.js`     | 研究兴趣                                        |
| `data/experience.js`   | 教育与工作经历                                     |
| `data/projects.js`     | 科研项目                                        |
| `data/publications.js` | 代表性成果                                       |
| `data/service.js`      | 学术服务、荣誉、竞赛                                  |


## 部署到 GitHub Pages

1. 将仓库推送到 GitHub 的 `main` 分支。
2. 打开仓库的 **Settings → Pages**，**Source** 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
3. 在 **Settings → Actions → General** 中确认已允许 Actions 运行。

仓库名为 `<用户名>.github.io` 时，访问地址为 `https://<用户名>.github.io`；其他仓库名则为 `https://<用户名>.github.io/<仓库名>/`。
